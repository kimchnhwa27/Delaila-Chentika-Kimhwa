# Data-Analyst-Portofolio

Welcome to the code repository for my personal portfolio website. This static website project was independently designed and developed to showcase my professional profile, technical skills, and recent project track record.

This project was specifically crafted to fulfill the course requirements for Data Warehousing and Business Intelligence. The development directly aligns with the objectives of the *Lab - Research Portfolio Requirements*, which entails creating a portfolio to highlight data analyst competencies, including technical proficiency in SQL, Microsoft Excel, Statistics, and Data Visualization. Furthermore, the repository structure is built to meet the criteria for file management and version control using GitHub.

I am Delaila Chentika Kimhwa, an Information Systems undergraduate student at UIN Syarif Hidayatullah Jakarta. Driven by a keen curiosity for numbers and problem-solving, I am an enthusiast in Data Analytics and Machine Learning. Through this website, I document my comprehensive journey from applying structured analytical thinking to hands-on experimentation in uncovering insights from real-world datasets.

This website is built entirely with core web fundamentals, without relying on heavy external frameworks. The main structure utilizes semantic HTML5, while the visual layout and responsiveness are handled using CSS3 via Flexbox and Grid. To enhance the user interface, I integrated the Poppins typeface from Google Fonts along with icons from Font Awesome. Vanilla JavaScript logic is also included to automatically detect and highlight the active page in the navigation menu.

The directory structure is organized to ensure maintainability. At the root level, visitors can find the primary files representing the home, profile, and portfolio pages. All supporting assets, such as stylesheets and image collections, are isolated and centrally stored inside the source directory (`src/`).

If you would like to review or run this project on your local machine, the steps are straightforward. You only need to download the files from this repository and open the `index.html` file using any modern web browser. No additional software installations or complex local server configurations are required, as the entire project relies on a static web architecture.
